# Reference only

This directory contains the upstream Unit-3 Hyprland configs, kept for
reference. They are **not** loaded into the running session.

The live Hyprland configuration is generated by Home Manager from:

- `main/home/hyprland/settings.nix`
- `main/home/hyprland/binds.nix`
- `main/home/hyprland/monitors.nix`
- `main/home/hyprland/windowrules.nix`
- `main/home/hyprland/exec-once.nix`

and lands in `~/.config/hypr/hyprland.conf`.

Add/edit keybinds in `main/home/hyprland/binds.nix`, not here.
